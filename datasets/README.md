# Synthetische Testdaten

Alle Dateien in diesem Ordner sind synthetisch. Sie enthalten keine echten
personenbezogenen Daten.

Die IBAN `DE89 3704 0044 0532 0130 00` ist die bekannte, öffentlich
dokumentierte Beispiel-IBAN. Die E-Mail-Adresse verwendet die für Beispiele
reservierte Domain `example.de`. Namen, Anschriften und Nummern sind erfunden.

Die Dateien dienen dazu, die Kette aus Einlesen, PII-Erkennung, Chunking und
Suche zu prüfen. Wer eigene Fälle beitragen möchte, legt hier eine weitere
synthetische Datei ab und ergänzt einen Test unter
`tests/regression/german/`.
